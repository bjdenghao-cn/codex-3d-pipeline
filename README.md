# 3D流水线 V1.4｜公开通用版

一套真实可安装、可运行的 Codex Skill，用于组织 1–30 秒 UE 质感 3D 广告的 Blender → Godot 制作流程。

> “UE 质感”是画面目标；当前自动编排与渲染引擎为 Godot 4。

## 直接下载

[下载 3d-pipeline-v1.4-public.zip](https://github.com/bjdenghao-cn/codex-3d-pipeline/raw/refs/heads/main/3d-pipeline-v1.4-public.zip)

## 安装

1. 下载并解压 ZIP。
2. 确认最外层文件夹名为 `3d-pipeline`。
3. 将整个文件夹复制到：`C:\Users\你的用户名\.codex\skills\3d-pipeline`。
4. 重新启动 Codex。
5. 输入：`使用 $3d-pipeline，先检查我的电脑和项目环境。`

## 基础环境

- Codex
- Python 3
- Blender
- Godot 4
- FFmpeg / FFprobe
- 默认 V1.4 九阶段路线需要 Blender MCP 实时连接

Mixamo 是按项目使用的外部服务，不是插件。Godot 默认使用 CLI/GDScript，不要求 Godot MCP。

## 验证

本公开包已经通过 28 项单元测试、Skill 结构校验以及 15 秒项目初始化冒烟测试。
